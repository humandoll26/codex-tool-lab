# 稽古・連絡調整 — 実装作業

対象はこの子フォルダとOSのモジュール登録・予定集約・テスト。稽古日・開始／終了・稽古場・参加役割・欠席／遅刻・必要スタッフ・内容・連絡事項を管理します。全体連絡文とCSVを書き出し、日時／場所の変更履歴を明示操作で残します。

完了条件は[追加MVP仕様](../../docs/mvp-v0.3.md)のNEXT-01〜NEXT-06の該当項目。テストはOS直下からnpm test／npm run test:browserを実行し、[作業記録](../../artifacts/progress.md)と[検証結果](../../artifacts/verification.md)に実測を残します。外部API・DB・依存を追加しません。
