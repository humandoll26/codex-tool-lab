# 申請・劇場提出物

提出物・提出先・担当ラベル・期限・提出日・差戻しを管理します。提出済みには提出日が必要です。提出物CSVを書き出せます。

入口は[index.html](index.html)。OSと同じHTTPサーバーで開き、同じ公演を参照します。[OSの起動とテスト手順](../../README.md)に従ってください。

- [モジュール仕様](SPEC.md) / [実装作業](TASK.md)
- データはproject.modules.submissions.data（version:1）。既存の公演・保存キー・JSON契約を使用します。
- [追加MVPの受入条件](../../docs/mvp-v0.3.md) / [検証結果](../../artifacts/verification.md)
- 日時は日本時間。カレンダーに集約し、該当行へ移動できます。
- 個人の連絡先は扱いません。役割や担当ラベルで管理してください。外部サービスへの自動送信は行いません。
- OS内の独立した入口です。shared/を参照するため、このフォルダだけの販売用配布物は未定義です。
