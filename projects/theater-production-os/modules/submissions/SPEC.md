# 申請・劇場提出物 — MVP v0.3

提出物・提出先・担当ラベル・期限・提出日・差戻しを管理します。提出済みには提出日が必要です。提出物CSVを書き出せます。

データの具体項目・日付と状態の判断は[追加MVP仕様](../../docs/mvp-v0.3.md)、公演と保存は[共通契約](../../docs/data-contract-v0.1.md)に従います。モジュール固有のモデルと画面はmodel.js／editor.jsに配置します。

妥当な入力だけを保存し、不正入力で前の保存を壊さないこと。JSON往復で入力と安定IDを保持すること。CSVは共通の数式無害化を使用。カレンダー連携・375pxでの編集・HTML風入力の非実行を[検証記録](../../artifacts/verification.md)で確認します。
