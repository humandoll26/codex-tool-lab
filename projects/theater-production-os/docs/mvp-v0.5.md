# MVP v0.5 — 劇場・作品権利・当日運営

継続指示に基づき、統合仕様5章の残る3工程に最小の作業支援を追加する。既存11モジュールと旧JSON契約を維持する。

- venue: 候補名・候補日・候補／仮押さえ／本予約／取消、仮押さえ期限、利用料・支払済み額・支払期限、同日内の搬入／搬出時刻、連絡担当ラベルとメモ。選択した候補を明示操作で公演マスターの劇場名へ反映する（公演日時・費用は自動で置換しない）。本予約には候補日を必須とする。複数予約日は行を分ける。
- rights: 作品名・作者表記・上演時間（分）・脚本／必要スタッフのメモ、権利確認事項・窓口役割・期限・未確認／照会中／確認済み／不要・確認日・許諾根拠メモ。確認済みには確認日と根拠を要求する。法的な許諾判断や権利者への自動連絡はしない。確認事項一覧CSVと作品概要テキスト。
- show-day: 日時・区分（受付／客席／物販／トラブル／アナウンス）・内容・担当役割・未対応／対応済み・数量・単価・備考。物販のみ数量×単価の参考売上を集計、トラブル未対応件数と当日記録を出力。個人の氏名・予約者名簿は扱わない。返品／在庫／決済は未対応。物販売上は実収入の確認後に決算へ手入力し、自動二重計上しない。
- カレンダーは会場候補日・仮押さえ／支払期限・権利確認期限・当日記録を行にリンクする。同一行から複数予定が出る場合も予定IDを分ける。
- 12工程＋稽古／提出物の14モジュールに最小機能を接続する。完全な制作実務、販売用配布物やクラウド同期の完成とは扱わない。

## 受入条件

- FINAL-01: 3入口で編集・保存・JSON往復、旧11モジュール保持。
- FINAL-02: 会場名の明示反映、本予約日の必須、支払超過・時刻範囲・仮押さえ期限エラーの保存保護。予定IDの重複なし。
- FINAL-03: 権利確認済みの確認日と根拠必須、不要の期限除外、原稿テキスト・CSV。
- FINAL-04: 物販売上の正確な合計と安全な整数範囲、未対応トラブル集計、時刻順の記録、決算を自動変更しない。
- FINAL-05: 375px入力・予定から行への移動・再読込、HTML風入力の非実行、外部通信・自動ダウンロードなし。

原本転記は変更しない。Google警告・実機Safari・税務・個人情報・販売ライセンスは別の未完事項。
