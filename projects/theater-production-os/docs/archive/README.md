# 設計資料のアーカイブ

ここには差し替えた旧仕様と完了済みの作業指示を保存する。現時点でアーカイブ済み資料はない。

1. PR採用と受入条件の検証後、完了したTASKを `YYYY-MM-DD-<topic>/TASK.md` に保存する。
2. SPECの範囲や版を差し替える場合は、その前のSPECも同じフォルダへ保存する。
3. フォルダのREADMEに状態、対応PR/コミット、旧版、後継ファイル、差し替え理由を記す。
4. 現行SPECと次のTASKはプロジェクト直下に残す。完了した実装の仕様は引き続き参照可能にする。

ビルド成功だけで移動しない。Git履歴を基本とし、節目の保存に使う。大量の重複スナップショットは作らない。
`docs/specs/theater-production-os-spec-v0.1.md` は今回取得した原本の記録として残す。
アプリ機能の公演アーカイブやビルド出力はここに置かない。
