# MVP v0.15 — 助成金・協賛・広告

原本6章Cに基づき、funding子フォルダへ17番目のモジュールを追加する。

- 助成金／協賛／広告の種別、案件名・団体名、候補／準備中／申請・確認中／採択・確定／不採択・辞退／取消を記録する。
- 採択・確定額、入金済み額、入金日、入金予定日を手入力する。金額は0以上の安全な整数円。入金済み額は確定額以下、正額の入金は採択・確定または取消の状態と入金日を必要とする。
- 助成金の申請締切・報告期限／未提出・提出済み・不要／提出日、広告の枠名・入稿期限／未受領・受領済み・不要／受領日を管理。広告には枠名必須。提出済み／受領済みには対応日付必須。未定の予定日は空欄を許容する。
- 採択・確定額の見込み集計、取消も含む入金済み額、採択・確定分の未入金額を区別。取消で実際の入金を消さない。返金・複数回の入金履歴は扱わない。
- 助成金の申請／報告、広告入稿、入金の予定をカレンダー・ダッシュボードへ集約し、行へリンク。申請は申請・確認中以降で完了、報告は提出済み／不要、入稿は受領済み／不要、入金は全額受領で完了。取消・不採択は未完了予定を取消にする。
- CSV・全公演／専用JSON・共有資料に対応。初期共有で金額や備考を出さず、作業データ選択時も既知項目だけを出す。バックアップは未知拡張を保持。
- 旧保存キー／schemaVersion:1を維持。旧funding形式は無断置換しない。決算への自動加算、申請・投稿の実行、実ファイル保管、口座接続・決済は追加しない。担当者の個人情報は記録しない。

## 受入条件

- FUND-01: 種別ごとの記録・375pxの編集・再読込、他モジュール保持、未入金／取消後の入金済み額を確認。
- FUND-02: 不正な金額・合計超過・日付・状態・重複ID、超過入金、入金日／報告日／入稿日不足、広告枠不足を拒否し、保存済み値を保持。
- FUND-03: 申請・報告・入稿・入金を固有IDで集約、行リンクと期限超過を確認。完了・不要・不採択・取消で不要な超過を止める。
- FUND-04: CSVの式文字化、専用JSONの対象だけの復元／旧拡張保持、共有の金額初期除外と未知拡張除外。
- FUND-05: 旧形式を無言で置換せず、全入口の通信・機微API／攻撃入力、明示出力と既存保存・印刷・上限試験を維持。
