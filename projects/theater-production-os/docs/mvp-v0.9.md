# MVP v0.9 — 公演アーカイブと引継ぎ

原本6章Fの公演アーカイブを15番目の独立した入口として実装。完成資料の所在と公演後の引継ぎを、ブラウザ内に記録する。

- 資料一覧: 名称、区分（チラシ／パンフ／写真／映像／脚本／収支／その他）、収集期限、未収集／所在記録済み／不要、保存場所・保管担当役割・所在記録日・備考。所在記録済みは場所と記録日を必須とする。実ファイルの存在・権利・バックアップを保証しない。
- 保存場所は文字列として表示・出力する。URLを自動で開いたり、ファイルを取得・アップロードしない。公演マスターのdocuments拡張を置換しない。
- 実来場者数は未入力をnullで保持し、販売枚数と区別。SNS実績メモ、反省点、次回への引継ぎを入力。来場者数に席数上限を課さない（延べ数や無料入場を含み得る）。
- 明示ボタンで現在の収支・実績レポートを1件保存。入力済み決算明細が必要。保存日時と公演IDを保持し、マスター変更後も自動更新しない。同じ原稿は重複保存せず、別原稿で置換する場合は確認。削除も確認。確定した決算や全データの履歴ではなく、保存時点の原稿。
- アーカイブ原稿のプレビュー／コピー・テキスト、資料一覧CSV・JSON保存と予定集約。所在記録済み／不要の収集期限は超過から除外。
- 保存キーとschemaVersion:1を維持。個人名簿・実ファイル・署名・権利認定・複数公演アーカイブ検索は追加しない。

## 受入条件

- ARCH-01: 入口・保存・JSON往復、既存14モジュールとdocumentsの拡張を保持。
- ARCH-02: 資料の場所と日付必須、来場者数の未入力・0・負数／小数、予定の行リンクと完了除外。
- ARCH-03: 明示レポート保存・同じ原稿の重複防止・変更後も保存原稿不変、置換／削除の取消と承認、決算なし・不正入力の保存拒否。
- ARCH-04: 原稿・CSV・375px表示、保存場所のHTML／URLの非実行・外部通信／自動ダウンロードなし。
