# MVP v0.8 — 公演収支・実績レポート

原本12章の公演終了後の収支・実績レポートを、決算モジュールの読取専用集計として追加する。既存の明細CSVは保持し、レポートのプレビュー・コピー・テキスト／CSV書出しを明示操作で行う。

- 入力済みの決算明細から実収入／経費／収支、入金／支払／資金収支、未収／未払、区分別集計と未決済明細を出力。
- 予算がある場合は想定販売・売上・費用・収支と、入力済み決算との差を表示。差額の符号は「決算−予算」、費用差額は節約額ではない。差額はBigIntで計算して大きい整数も丸めない。
- 販売進捗の実績枚数・残席・販売率、ステージ別枚数、現行料金による参考売上を別項目にする。実入場者数や過去の実収入とは扱わない。
- 当日物販の数量／参考売上と未対応トラブル件数を参照。実収入へ自動加算せず二重計上しない。釣銭は収入・費用に加算しない。
- 参照モジュールが未入力・旧形式なら集計対象外と明示。未入力の決算区分は0円で集計し、入力件数と未確定・未入力の可能性を記載。
- 保存契約に項目を追加せず、レポート操作でJSONを変更しない。税務・会計帳票の確定、予算履歴の凍結、監査証明は対象外。

## 受入条件

- REPORT-01: 実収入と現金収支、未収／未払・区分別・未決済一覧が明細と一致し、参考売上を加算しない。
- REPORT-02: 予算比較・枚数比較・ステージ別集計と現在価格の反映。価格変更で入力済み実収入は不変。
- REPORT-03: 参照の未入力／旧形式・0席・負の収支と、安全な整数同士の差が安全整数範囲を超える場合を正確に表示。
- REPORT-04: プレビュー追随・コピー・テキスト／CSV書出し、不正入力で出力を拒否、375pxの入力と表示、保存データ不変。
- REPORT-05: HTML風文字列の非実行・CSV数式無害化と外部通信／自動ダウンロードなし。
