# MVP v0.3 — 稽古・提出物

2026-10-01の継続実装指示に基づき、統合仕様6章の優先度「高」の2モジュールを追加する。

- rehearsal: 稽古名・日付・開始／終了時刻（日本時間、同日）・稽古場・参加役割ラベル・欠席／遅刻メモ・必要スタッフ・稽古内容・連絡事項・予定／完了／中止。全体連絡用テキストとCSV。日時／場所の変更履歴は「予定変更を記録」を押す明示操作で保存し、同じ内容は重複しない。日跨ぎと個人の連絡先は対象外。
- submissions: 提出物名・提出先・種別・担当ラベル・期限・準備中／未着手／提出済み／差戻し・提出日・備考。提出済みには提出日必須。遅れて提出した日付も保持する。CSVと集計。ファイル添付や外部への自動提出は対象外。
- 個人の本名・電話・住所等ではなく役割や担当ラベルで管理する。既存のブラウザ内保存・JSON契約とCSV安全化を使用。
- 7モジュールをOS・単体入口から利用。稽古日時と提出期限をカレンダーへ集約し、作業行に移動。完了／中止稽古と提出済み書類は期限超過から除く。
- 既存の5モジュール、逆算6予定、保存キー、schemaVersion 1を保持。未作成の追加モジュールは未着手。異なる旧形式は確認なしに置換しない。
