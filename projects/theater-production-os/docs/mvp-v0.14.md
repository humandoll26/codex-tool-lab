# MVP v0.14 — 契約・支払いの作業管理

原本6章Bに基づき、contracts子フォルダに16番目のモジュールを追加する。

- 名称・担当役割ラベル、準備中／確認依頼中／合意済み／取消、0以上の安全な整数円、請求書未受領／受領済み／不要、受領日、支払予定日、未払／支払済み、支払日、備考を管理する。金額は手入力の税込総額。
- 受領済みには受領日、支払済みには支払日が必要。日付は日本時間の暦日。支払予定日は未定なら空欄を許容。分割払い・返金は扱わず、金額全体の支払状態を記録する。
- 取消以外の契約金額・未払額と未受領件数、取消も含む支払済み額を区別する。準備中・確認依頼中の額も含む見込み集計で、会計上の確定債務ではない。取消時も支払済み記録を消さない。
- 支払予定をカレンダー・ダッシュボードへ集約。支払済み／取消は期限超過対象から除く。行リンクで入力へ戻る。
- CSV・全体JSON・専用JSON・共有資料に対応。共有資料の初期値は金額や備考を含まない。未知拡張は共有資料に含めず、バックアップでは保持する。
- 従来のschemaVersion:1、保存キー、旧モジュールの入力と拡張保持を維持。未実装だったcontractsの旧形式を無言で置換しない。
- 外部通信、実ファイル保管、個人名簿、決済、口座・カード情報、税務計算、電子署名、決算への自動転記は追加しない。税務に関する確認は備考で記録できる。

## 受入条件

- CONTRACT-01: 375px幅で追加・編集・再読込でき、契約入力・他モジュール・共通情報を保持する。
- CONTRACT-02: 負数／小数／不正な日付／状態／重複ID／合計超過と日付必須を検証し、保存済み値を壊さない。0円を許容する。
- CONTRACT-03: 未払予定が期限超過と行リンクに反映され、支払済み／取消で対象外になる。取消後の支払済み額は残る。
- CONTRACT-04: CSVの数式入力を文字化し、専用JSONは同じ公演だけに復元できる。共有の初期出力は金額なし、作業データ選択時は既知項目だけ。
- CONTRACT-05: 新入口の操作と出力で外部通信／無断ダウンロード／HTML実行がなく、全既存検証を維持する。

未定義の販売用配布物・ライセンスは今回具体化しない。Notion正本は変更しない。
