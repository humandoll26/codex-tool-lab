# MVP v0.7 — カレンダー書き出し

原本12章のiCalendar（.ics）書き出しを実装する。カレンダーに表示中の月／今週／今日、日選択、モジュールフィルタを適用した予定を、明示操作でICSとCSVに保存する。空の一覧では案内し、不正入力では書き出さない。データを送信・変更しない。

- 時刻のある予定は日本時間をUTCに変換。稽古と舞台作業は入力済みの終了時刻も保持。本番と当日記録には未入力の終了時刻を作らない。日付だけの予定は終日扱い。
- 公演・予定IDに基づく固定UID。保留はTENTATIVE、中止はCANCELLED、完了は説明に記載し時間を占有しない。再取込の重複・更新の扱いは受け側に依存し、同期や削除通知は行わない。
- 日本語の行をUTF-8の75バイト以内で折返し。改行・区切り文字はiCalendarのTEXT形式でエスケープ。CSVでは数式風の入力を無害化。
- カレンダーアプリでの実機取り込みは未検証。Googleアカウントとの接続・自動同期・招待・参加者名簿は追加しない。

## 受入条件

- CAL-01: 日本時間の時刻と終了をUTCに変換。終日と時刻未定の終了を正しく区別。
- CAL-02: UIDの安定性・予定間の識別、状態の変換と完了の説明。
- CAL-03: 日本語・絵文字・改行・区切り文字で行注入せず、折返しで文字を欠落しない。
- CAL-04: 月／日／今週／今日とモジュール条件に一致する件数を出力し、空一覧／不正入力は保存を保護。
- CAL-05: CSVとICSの手動ダウンロード、JSON不変、外部送信・自動ダウンロードなし。
