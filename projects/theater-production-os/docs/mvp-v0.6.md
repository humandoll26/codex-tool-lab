# MVP v0.6 — 操作改善

14モジュール接続後のスマホ操作を改善する。

- 画面上部の「作業モジュール」選択で直接移動。入力エラーまたは保存失敗中は移動せず、選択を現在の画面に戻す。公演IDを引き継ぐ。
- 他モジュールの修復フォームは、そのモジュールに入力／参照エラーがあるときだけ生成する。エラーを直している途中では閉じたり消したりせず、入力フォーカスを保持。自動保存・旧データ契約は変更しない。
- 月間カレンダーで日付を選ぶと、その日の予定一覧を表示。「月全体の予定に戻す」で解除。月と表示範囲を変更したら日付選択を解除する。モバイルの月間マスは短いラベルと件数を表示し、完全な予定名は一覧で読む。
- チラシに加え、稽古連絡文・当日案内・パンフ掲載文・舞台進行表・作品概要・当日記録を画面内でプレビューできる。コピーはボタン操作時だけ実行。利用不可ならプレビューを選択して手動コピーを案内する。書出しは従来どおり明示操作。

- ダッシュボードは今日／今週・期限超過をモジュールカードより前に表示。一覧を名称／ID検索と状態で絞り込み、検索中のフォーカスを保持する。絞り込みは表示だけで保存データを変更しない。

## 受入条件

- UX-01: 作業切替で公演ID・データを保持。不正入力・保存失敗では移動しない。
- UX-02: 正常時は他モジュールの編集入力なし。マスター変更で他モジュールのエラーが発生したら修復フォームを表示し、その場で修正・保存できる。
- UX-03: 月間の日選択・解除・フィルタ、月／範囲変更による解除、375px表示。
- UX-04: 原稿プレビューは入力に追随し、HTML風入力を実行しない。全既存テストと外部送信・自動ダウンロードなしの検証を維持。

- UX-05: ダッシュボードの予定優先表示、一覧検索／状態絞り込み、検索のフォーカス維持、長いタイトルでも375px横溢れなし。

- 予算に想定販売・費用明細のテキスト／CSV出力とプレビュー・コピーを追加。実績とは別で、基準料金の損益分岐の前提を記載。
- UX-06: 予算のサンプル計算と出力一致、現在価格反映、CSV数式無害化、空席／黒字化不可の説明、不正入力の書出し禁止。
